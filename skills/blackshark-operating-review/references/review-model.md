# Operating review model

## Evidence matrix

| Layer | Question | Typical evidence | Invalid shortcut |
| --- | --- | --- | --- |
| Execution | Did the agreed action occur as specified? | completion record, delivery, observed deviation | assuming completion from assignment |
| Customer behavior | Did the target person act differently? | purchase, visit, return, choice, response | equating exposure or praise with behavior |
| Store/business | Did the store result change within the defined window and comparison? | orders, revenue, gross profit, repeat, cost | ignoring baseline, window, transfer, or cost |
| Brand/network | Did shared demand or role fit improve without harming protected operations? | cross-store/new-demand evidence, role fit, durable brand signal | counting internal transfer as growth |
| Method | Is the method reusable beyond this case? | repeated real samples, independent use, boundaries, counterexamples | promoting from one success or a fixed count |

## Conservative state updates

- Continue: evidence is incomplete but no stop condition is met, or evidence supports continued use within the same boundary.
- Adjust: evidence identifies a changed premise or a specific execution/design correction.
- Complete: the original acceptance condition, not merely the activity, has been met.
- Stop: the stop condition is met, required protection fails, or the hypothesis is no longer worth pursuing.

No new action is a valid review outcome. “Continue observing” should name only the already-agreed evidence window or source; it must not silently add scope.

## Knowledge decision

Record `no new reusable knowledge` when the review only confirms uncertainty, repeats a known boundary, or lacks evidence. When new knowledge exists, state the claim, evidence, scope, confidence, counterexample, and what would invalidate it before considering promotion.
